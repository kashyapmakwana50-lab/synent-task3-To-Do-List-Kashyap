# To-Do List 📝

A simple command-line To-Do List application written in Python.

## Features

* Add tasks
* Delete tasks
* View all tasks
* Simple menu-based interface
* Handles empty task lists

## How to Run

Make sure Python 3 is installed, then run:

```bash
python task3.py
```

## Example

```text
===== TO-DO LIST =====
1. Add Task
2. Delete Task
3. View Tasks
4. Exit

Enter your choice: 1
Enter task: Learn Python
Task added successfully!
```

## Requirements

* Python 3.x
* No external libraries required

## Note

Tasks are stored temporarily while the program is running. They will be lost when the program is closed.
